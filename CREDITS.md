# Credits

## Art, audio and fonts

All by [Kenney](https://kenney.nl), released under CC0 (public domain). Each
pack keeps its `License.txt` next to the files.

| Pack | Used for |
|---|---|
| Coaster Kit | Paths, queues, stalls, stations, trains, scenery and the park gate |
| Mini Characters | Guests and janitors |
| Emote Pack | Guests' thoughts over their heads |
| Input Prompts | Controller and keyboard button glyphs |
| UI Pack - Adventure | Menus and panels |
| Kenney Fonts | All text |
| Music Loops | Music |
| Interface Sounds, Casino Audio | Sound effects |

The coaster track and its supports are built in code from each ride's shape.
